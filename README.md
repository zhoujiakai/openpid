# openpid

> 工业过程智能优化 — PID 控制 · 时序分析 · 强化学习 · PHM

面向工业 AI 方向的个人项目，覆盖工业过程优化方向所需的核心技能：

- **PID 控制**：比例-积分-微分控制，工业过程控制基础
- **时序分析与预测**：LSTM / Isolation Forest 等用于工艺指标预测与异常检测
- **强化学习**：DQN 策略网络用于工艺参数优化
- **PHM（预测性维护）**：设备健康度评估、RUL 预测

## 目录结构

```
openpid/
├── control/        # 控制算法（PID、模糊控制、RL 优化）
├── phm/            # 设备健康管理（异常检测、RUL 预测）
├── data/           # 模拟工业时序数据
├── examples/       # 完整流程示例
└── requirements.txt
```
